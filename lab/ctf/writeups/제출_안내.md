# Write-up(풀이 보고서) 제출 안내

대회 상금·최종 순위 확정 조건으로 **write-up 제출이 필수**입니다. 플래그만 맞혀도 제출이 없으면
해당 문제의 점수/상금 인정이 보류될 수 있습니다. (정확한 패널티 기준은 운영진 공지로 — [기준 자리표시])

## 분량·형식
- 문제당 1~2쪽 정도. 길이보다 "다른 사람이 읽고 재현할 수 있는가"가 중요합니다.
- 최소 제출 범위: [본인이 푼 문제 전부 / 또는 최소 N문제 — 운영진 확정 자리표시]
- 형식: Markdown(.md) 또는 PDF. 스크린샷은 문서에 넣거나 별도 이미지로 함께.

## 꼭 들어가야 하는 것
1. 문제 이름(F1~F6)과 획득한 플래그 (앞뒤 일부 마스킹 가능)
2. 접근 과정: 정찰 → 세운 가설 → 시도 (성공만 말고 **실패·삽질도** 적기)
3. 성공 재현 과정: 실제 쓴 요청/명령과 그 응답 (복붙 가능하게)
4. 스크린샷: 결정적 화면 1~2장
5. 배운 점과 대응방안(실무라면 어떻게 막는지)

## 하면 안 되는 것
- 플래그 값 통째로 공개 채널에 공유 금지 (write-up 안에서도 마스킹 권장)
- 다른 팀 계정·자격증명·플래그를 쓰거나 공유 금지 (제출물 교차 검증합니다)

## 제출
- 기한: [대회 종료 후 OO시간 이내 / 날짜·시각 자리표시]
- 제출처: [CTFd 업로드 / 이메일 / 제출 폼 링크 자리표시]
- 파일명 예: `t0X_문제번호_writeup.md`

## 작성 예시
[예시_커맨드인젝션_이미지.md](./예시_커맨드인젝션_이미지.md) — 이 정도 디테일이면 충분합니다.
(이 예시는 대회 문제와 겹치지 않는 별도 연습 서버로 만든 것입니다.) 톤은 자유롭게, 본인이 실제로
겪은 순서대로 솔직하게 쓰면 됩니다. 매끈하게 꾸미지 않아도 되고, 막힌 지점·헛짚은 가설이 오히려 좋은 자료예요.
