# 본 대회 운영 런북 (10팀)

대회 시간: **2026-11-25(수) 13:00 ~ 11-26(목) 21:00 KST** (약 32시간)
실행 위치: **운영자 PC**(terraform 상태가 여기 있음). 리전 ap-southeast-2(시드니).

## 0. 준비 확인 (한 번)
- [ ] 운영자 PC에 terraform, aws CLI, jq 설치됨
- [ ] AWS 자격증명(운영진)·리전 ap-southeast-2 설정됨 (`aws sts get-caller-identity`)
- [ ] 레포 최신화: **PR #52 병합 후** `git checkout main && git pull`
  (site.zip은 terraform이 `lab/ctf/site`를 자동으로 압축·업로드하므로, 병합된 최신 코드여야 함)

## 1. 배포 — 시작 1시간 전(≈11/25 12:00 KST)
```bash
cd lab/ctf/terraform
terraform init      # 최초 1회
terraform apply \
  -var 'team_count=10' \
  -var 'contest_open=false' \
  -var 'operator_cidrs=["<운영자_공인IP>/32"]'
# → 10팀 서버 + CTFd + ALB + WAF 생성. 이 시점엔 운영자 IP만 접속 가능.
```

## 2. 플래그·설정 주입 (apply 직후)
```bash
cd lab/ctf
bash inject_flags.sh        # 전체 팀. SSM Online 될 때까지 자동 대기
# 서버를 일부만 다시 만들었으면: bash inject_flags.sh t03 t07
```
- F1~F4 파일·sudo 규칙·기본인증 비번·F6 버킷을 SSM으로 주입(user-data 노출 방지).
- 플래그 값은 화면에 안 찍힘.

## 3. 팀별 배부 정보 추출
```bash
cd lab/ctf
bash handout.sh             # 화면 표 (팀 / 사이트 링크 / ID / 기본인증 비번)
bash handout.sh --csv > ~/teams_handout.csv   # CSV로 저장해 팀별 전달
```
- **ID = 팀명(t01…), 비밀번호 = 팀별 랜덤값.** 각 줄을 해당 팀에게만 비공개 전달.
- CTFd 점수판 주소(모두 공통, 플래그 제출처)도 함께 출력됨.
- (정답지 `terraform output -json flags`·`team_instances`는 운영진 전용, 공유 금지.)

## 4. 대회 오픈 — 11/25 13:00 KST
```bash
cd lab/ctf/terraform
terraform apply -var 'team_count=10' -var 'contest_open=true' \
  -var 'operator_cidrs=["<운영자_공인IP>/32"]'
# → ALB 팀 포트·CTFd를 0.0.0.0/0에 개방(전체 공개).
```
- 공용 NAT 뒤에 여러 명이 몰리면 그 IP를 WAF `shared-venue-ip` 세트에 추가(레이트리밋 500/5분).

## 5. 종료 — 11/26 21:00 KST
```bash
cd lab/ctf/terraform
terraform apply -var 'team_count=10' -var 'contest_open=false' \
  -var 'operator_cidrs=["<운영자_공인IP>/32"]'   # 먼저 외부 접속 차단
# (CTFd check-sharing 등 정산 끝난 뒤)
terraform destroy -var 'team_count=10'            # 전부 삭제 — 과금 중단
```
- **반드시 destroy.** 안 지우면 하루 약 $10, 한 달 방치 시 $300+.

## 비용 요약 (32시간 × 10팀, 시드니 정가)
- 크레딧 적용(현재 계정): **$0** (크레딧으로 충당)
- 정가 환산(부가세 포함): **약 $15.7 ≈ 22,000원** (대부분 EC2 11대)
- 상시 가동 전제. 끝나고 destroy만 하면 추가 비용 없음.

## 문제 생길 때
- 특정 팀 사이트 500/락아웃: `aws ssm start-session`(또는 재-inject) 후 `/var/log/ctf-bootstrap.log` 확인.
- SSM Online 안 됨: 2~3분 더 대기(부팅 중). 계속 안 되면 그 팀만 terraform taint 후 재생성 + 재-inject.
- CTFd 문제/힌트 미등록: `lab/ctf/ctfd/ctfd_setup.py setup ...` (토큰 필요).
