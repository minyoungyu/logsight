규칙만 틀린 3개 중 2개는 '이 계정은 우리 팀'이라는 한 줄(정상 작업 목록)로 풀린다. AI가 추가로 푼 것은 INC-003 하나다. 규칙은 이것을 '판단 불가'로 남기고 '그 IP가 우리 것인지 확인하라'고 적었으므로, 틀린 판정을 낸 것은 아니다.

## 읽는 법(과장하지 않기)

- **AI의 몫은 생각보다 작다.** 판정 정확도 차이(6/7 → 7/7)는 사건 1개다. 큰 차이는 '정상 작업 목록'을 넣었을 때(4/7 → 6/7) 났다. 그래서 기본값을 '규칙 + 정상 작업 목록'으로 두고 AI는 선택으로 둔다는 지금 설계와 맞는다.
- **AI가 실제로 더해 주는 것은 설명이다.** 묶은 이유, 시간 순서 이야기, '모른다' 목록이 더 구체적이다(12개 대 8개). 단계 탐지 수는 같다(5/6). 탐지는 규칙이 한다.
- **독립 측정이 아니다.** 공방전 데이터는 규칙·가명 처리·프롬프트를 고치는 데 쓴 데이터다. 데이터 1개, 사건 7개라 통계적으로 의미 있는 차이라고 말할 수 없다. AI 재검토를 다른 데이터(BOTSv3, AIT)로 잰 결과는 아직 없다.
- **G3(PDF 내려받기)는 세 조건 모두 놓쳤다.** 403/404만 보는 IDOR 규칙의 한계다.

## 남은 일

- 다른 데이터(BOTSv3 AWS 등)에 규칙+AI를 돌려 같은 표를 채우기. 원본 데이터가 저장소에 없어 데이터를 가진 사람이 `python scripts/ctf/eval_gongbang.py --ai` 같은 방식으로 돌려야 한다.
