# CTF 본대회 로그로 S7·S6 판정 시도 (2026-11-26)

**[확인]** = 결과 파일·데이터로 확인, **[추정]** = 확인하지 못한 판단.

## 결론

- **S7(CTFd 접근 로그): 재지 않았고 판정도 없어요.** 고정한 사전 확인(`S7.data_precheck`)에서 떨어졌어요. [확인: `reports/public/ctf_main_precheck.json`]
  - 첫 칸의 서로 다른 값이 99개예요. 기준은 100개 이상이에요.
  - 한 공인 IP(운영자 IP 아님)가 줄의 96.9%를 차지해요. 기준은 50% 이하예요.
  - 줄 수도 17,102줄이라 계획의 30,000줄 조건에 못 미쳐요.
  - 요청 내용과 규칙 결과는 열어 보지 않았어요.
- **S6 보조(CloudTrail): 공격 세션이 0건이라 판정하지 않았어요.** [확인: `reports/public/ctf_cloudtrail.json`]
  - 팀 역할 호출 7,756건이 모두 각 팀 인스턴스의 사설 IP에서 나왔어요.
  - 빼낸 자격 증명을 밖에서 쓴 기록은 없어요.
- **이유:** 이번 대회에는 외부 참가자 접속이 없었어요. 운영 스레드 기록으로 점수판 로그인과 제출이 0건이고, 등록·제출 감사 로그는 0바이트예요.
- **그래서 S7 판정 데이터는 여전히 EClog 하나(0.496%, 미달)예요.** 고친 ROBOTS_HIDDEN과 규칙 성숙도의 효과를 판정하려면 새 처음 보는 데이터가 필요해요.
