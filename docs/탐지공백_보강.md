# 탐지 공백 보강 (2026-11-05, 개발 데이터)

[처음 보는 데이터 측정](처음보는데이터_측정.md)에서 놓친 행동과 Stratus Red Team 기법 목록([lab/aws/stratus](../lab/aws/stratus/README.md))을 보고
규칙을 더했다. **두 목록을 보고 만들었으므로 아래 숫자는 모두 개발 데이터 점수다.** 처음 보는 데이터 점수(31%)는 바꾸지 않는다.

## 오탐을 줄이려고 한 것

- 운영자가 평소 하는 작업과 모양이 같은 규칙(인스턴스 원격 명령, 함수 배포)만 걸린 사건은 '공격'이 아니라 **'판단 불가'**로 둔다.
  우리 팀으로 확인하면(`logsight team --confirm`) 다음부터 빠진다.
- 처음에는 DescribeInstanceAttribute를 '목록 조회'에 넣었는데, 공방전에서 루트 계정의 콘솔 둘러보기가 공격으로 바뀌었다.
  그래서 빼고, **시작 스크립트(userData)를 읽는 경우만** 비밀값 조회로 센다.
- 버킷 수명 주기는 이름에 trail·log·audit가 든 버킷만 본다. 일반 버킷의 정리 규칙은 걸리지 않는다.

## 아직 못 하는 것

- KMS 랜섬웨어 표본 2개는 여전히 놓친다(공격자 계정의 KMS 키로 다시 쓰는 수법).
- Bedrock 자원 삭제, ECR 이미지 취약점 결과, 콘솔 로그인 연속 실패, 여러 IP 동시 세션은 규칙이 없다.
- **새 처음 보는 데이터가 필요하다.** 실습 계정에서 Stratus를 돌리면 이번 규칙의 실제 효과를 잴 수 있지만,
  기법 목록을 보고 규칙을 만들었으므로 그 결과도 개발 데이터로 적는다.
