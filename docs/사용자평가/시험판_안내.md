# 시험판 써 보기 (30분)

본 실험([설계](설계.md), 8명·70분) 전에 3~5명에게 먼저 주는 짧은 시험이다. 목적은 점수가 아니라
**설치에서 막히는 곳과 보고서에서 이해 안 되는 곳**을 찾는 것이다. 결과는 본 실험 점수에 넣지 않는다.

## 누구에게

개발은 하지만 보안 담당 경험이 없는 사람. 팀원과 측정 데이터를 본 사람은 빼 둔다(본 실험에 쓸 수 있게).

## 보낼 것

1. 설치(둘 중 하나)
   - `pip install https://github.com/minyoungyu/logsight/releases/download/v0.4.1/logsight-0.4.1-py3-none-any.whl`
   - `docker run -p 8000:8000 ghcr.io/minyoungyu/logsight:0.4.1` → http://127.0.0.1:8000
2. 해 볼 것: 저장소의 `samples/combined`을 받아 `logsight analyze combined --out report --no-ai`, `report/report.html`을 연다.
3. 의견: GitHub 이슈의 **시험판 의견** 양식, 또는 같은 질문을 메시지로.

## 진행자가 볼 것

- 설치부터 보고서를 열기까지 걸린 시간, 막힌 단계
- 첫 화면에서 판정·고칠 곳을 말하기까지 걸린 시간(5분 기준)
- "믿기 어렵다", "무슨 뜻인지 모르겠다"고 한 문장 → 고칠 목록

릴리스: https://github.com/minyoungyu/logsight/releases (`.github/workflows/release.yml`이 설치 파일, 샘플 보고서, Docker 이미지를 만든다).
