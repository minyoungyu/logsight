# 질문지 (참가자용)

참가자 번호: ______  시나리오: ______  시작 시각: ______  끝낸 시각: ______

상황: 어제 이 AWS 계정에서 이상한 일이 있었다는 신고를 받았습니다. 받은 자료만 보고 아래에 답해 주세요.
모르면 "모름"이라고 적어도 됩니다. 문장으로 짧게 적으면 됩니다.

1. 공격이 있었나요? (있음 / 없음 / 모르겠음) 그렇게 본 근거 하나를 적어 주세요.

2. 공격자는 처음에 어떻게 들어왔나요? (어디로, 무엇을 이용해서)

3. 공격자가 쓴 계정이나 키는 무엇이고, 어디(IP)에서 썼나요?

4. 공격자가 실제로 한 일과, 성공했는지 실패했는지를 적어 주세요. 공격이 아닌데 위험한 일이 있었다면 그것도 적어 주세요.

5. 지금 당장 해야 할 조치 두 가지를 우선순위대로 적어 주세요.

6. 내 답이 맞을 거라고 얼마나 확신하나요? (1 전혀 아님 ~ 5 매우 확신)

7. 공격이라고 보기 쉬웠지만 실제로는 정상 작업이라고 판단한 것이 있었나요? 있었다면 무엇인가요?
