# 비전문가 3명 30분 파일럿 (2026-11-24 결정, 약점 3-B)

본 실험([설계.md](설계.md), 8명·70분·교차 설계)과 CTF 3자 비교([3자_비교평가.md](../CTF_사례/3자_비교평가.md)) 전에 하는 작은 시험이다.
**재는 것은 하나다: 보안 경험 없는 사람이 LogFinder 보고서만으로 질문지에 맞게 답하나.** 비교 조건이 없으므로 "LogFinder가 더 낫다"는 말은 이 결과로 하지 않는다.

## 1. 미리 정한 기준 (진행 전에 고정)

| 항목 | 기준 | 못 넘으면 |
|---|---|---|
| 점수 | 3명 평균 10점 중 **6점 이상**([정답_채점기준.md](정답_채점기준.md) 시나리오 B) | 보고서 첫 화면·판정 문구를 고치고 본 실험을 미룬다 |
| 오지목 | 직원 bstoll·btun을 공격자로 지목한 사람 **0명** | 규칙만 보고서는 직원 활동 4개를 '공격'으로 낸다(BOTSv3 측정 2절). 이것이 사람을 잘못 이끄는지 보는 핵심 항목이다 |
| 성패 구분 | 문항 4에서 web_admin 키의 시도가 "실패"였다고 쓴 사람 **2명 이상** | "실제로 뚫렸나" 문구(성공·실패 건수)를 더 눈에 띄게 |
| 시간 | 25분 안에 다 쓴 사람 2명 이상 | 보고서가 길다는 뜻. 요약 칸을 줄인다 |

## 2. 참가자

- 3명. 개발·운영 경험은 있고 보안 담당 경험은 없다.
- 빼는 사람: 팀원, BOTSv3 풀이를 본 사람, 11/26 CTF에 같이 나가는 사람(3자 비교의 B 평가자 후보도 뺀다).
- 결과는 P01~P03 번호로만 적는다.

## 3. 진행 (1인 30분)

1. (2분) 동의서 낭독([진행_대본.md](진행_대본.md) 2절과 같음)
2. (최대 25분) 묶음을 열고 [질문지.md](질문지.md)에 답한다. 말은 "어제 이 AWS 계정에서 이상한 일이 있었다는 신고를 받았습니다. 이 폴더의 자료만 보고 답해 주세요. 인터넷 검색은 하지 말아 주세요." 시작·끝 시각을 적는다.
3. (3분) 묻기: "믿기 어려웠던 문장, 무슨 뜻인지 몰랐던 문장을 짚어 주세요."

진행자는 힌트를 주지 않는다. 원격이면 화면 공유로 보고, 녹화는 동의한 경우에만 한다.

## 4. 준비물

- 묶음: 프로젝트 파일 `pilot/파일럿_묶음_BOTSv3.zip`(약 2.7MB). 안에 `B/logsight/report.html`(규칙 모드 보고서), `B/logsight/logs/`(원본 로그), `질문지.md`가 있다. 정답 파일은 넣지 않았다.
- 다시 만들기: `python scripts/study_prepare.py --scenario A=samples/combined --scenario B=<BOTSv3 추출 폴더> --participants 4 --year 2018 --out kit` 뒤 `kit/B/logsight`만 준다(스크립트가 교차 설계용이라 시나리오 두 개를 요구한다).
- BOTSv3 추출: `python scripts/public/botsv3_extract.py <botsv3 db 폴더> <출력 폴더>`
