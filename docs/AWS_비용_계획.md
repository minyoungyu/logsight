# 2단계 실습 AWS 비용 계산 (서울 리전, 2026-11-01)

> 단가: AWS Price List API의 서울(ap-northeast-2) 공식 요금 파일을 직접 내려받아 확인(EC2 요금 적용일 2026-10-01).
> 사용량은 가정이며 각 줄에 적었다. 크레딧·무료 사용량은 빼고 계산한 "최악이 아닌 보통" 값이다.
> 한국 주소 계정은 AWS Korea가 부가세 10%를 붙인다. 환율은 1달러 = 1,400원으로 가정했다.

## 결론

| 진행 범위 | 예상 비용(부가세 포함) |
| --- | --- |
| 중간보고 전 필수(실제 계정 읽기 점검 + 로그 켜기 검증) | **0~1달러(약 1,400원 이하)** |
| 2단계 전체(아래 1~5 모두, 깔끔히 정리한 경우) | **약 8.6~14달러(약 1.2만~2만 원)** |
| 정리를 잊고 한 달 방치한 경우 | **최대 수백 달러 가능** (NAT 게이트웨이가 가장 위험) |

**돈이 드는 건 "작업 자체"가 아니라 "정리를 잊는 것"이다.** 아래 안전장치를 먼저 걸고 시작하는 걸 전제로 한다.

## 1. 실제 계정 읽기 점검: 0달러

`logsight check`, `collect environment`, `collect cloudtrail-history`는 조회(Describe/Get/List/LookupEvents) API만 부른다.
조회 API 호출은 과금되지 않고, CloudTrail 이벤트 기록(90일)도 무료다. **0달러.**

## 2. 로그 켜기 검증(`check --apply`, 실습 계정에서 한 달 유지)

| 항목 | 서울 단가 | 가정 | 월 비용 |
| --- | --- | --- | --- |
| CloudTrail 관리 이벤트(첫 추적) | 무료 | 이벤트 수와 무관 | 0 |
| ├ S3 저장 | GB당 0.025 | 월 수 MB | 0.001 미만 |
| └ S3 쓰기 요청(로그 파일 전달) | 1,000건당 0.0045 | 월 2천~15만 건(다중 리전 추적은 리전마다 파일이 생김) | 0.01~0.68 |
| VPC Flow Logs → S3 | **GB당 0.38**(us-east-1은 0.25) | 작은 VPC 0.1~0.5GB + 쓰기 요청 | 0.08~0.23 |
| GuardDuty | 30일 무료 체험 | 첫 달 | 0 |
| └ 체험 후 계속 켜 두면 | CloudTrail 100만 건당 4.6, Flow·DNS GB당 1.15 | 이벤트 3만 건 + 0.3GB | 약 0.48/월 |

**검증 끝나고 GuardDuty를 끄면 0.1~0.9달러.**

## 3. 정확도 측정용 공격 재현(Stratus Red Team, 실습 계정)

Stratus 소스 코드(Terraform)를 직접 확인해 각 항목이 만드는 유료 자원을 셌다.
대부분(IAM, S3, Lambda 등)은 몇 분 쓰고 지우면 사실상 0원이다. 돈이 드는 것은 아래뿐이다.

| 유료 자원 | 해당 항목 수 | 단가(서울) | 1회 실행(1시간 이내 후 정리) |
| --- | --- | --- | --- |
| NAT 게이트웨이 + 고정 IP + t3.micro + 8GB 디스크 | EC2가 필요한 항목 7개(각자 따로 생성) | NAT 시간당 0.059, IPv4 0.005, t3.micro 0.013 | 항목당 약 0.08 → 7개 0.57 |
| RDS db.t3.micro + 10GB | 1개 | 시간당 0.026 | 약 0.03 |
| SageMaker 노트북 ml.t3.medium | 1개 | 시간당 0.062 | 약 0.06 |
| Secrets Manager 비밀 62개 | 2개 | 개당 월 0.40(시간 단위 일할) | 약 0.03 |
| 기타(S3, IAM, Lambda, 보조 추적) | 나머지 | - | 약 0.05 |
| **한 바퀴 합계** | | | **약 0.74달러** |

정확도를 반복 측정하려고 3번 돌리면 **약 2.2달러**. Bedrock 호출 항목은 모델 사용 신청이 필요하고 토큰 비용이 따로 들어 제외했다.
NAT 게이트웨이는 1시간 미만이어도 1시간 요금이 붙는다. 그래서 EC2 항목은 한 번에 하나씩 실행하고 곧바로 정리한다.

## 8. 시작 전 안전장치(모두 무료)

1. **실습 전용 계정**을 운영 계정과 분리해서 만든다. 새 계정이면 가입 크레딧(최대 200달러, 무료 플랜은 6개월 또는 크레딧 소진 시 종료)으로 위 비용이 사실상 0원이 된다. 무료 플랜에서 쓸 수 없는 서비스가 있는지는 가입 화면에서 확인해야 한다.
2. **AWS Budgets 알림**: 월 5달러 예산, 실제 50%·100%와 예상 100%에서 메일 알림.
3. **비용 이상 탐지(Cost Anomaly Detection)** 켜기.
4. 리전을 서울 하나로 고정하고, 모든 자원에 `project=logsight` 태그를 단다.
5. Stratus는 항목 하나씩 실행하고 끝나면 정리 명령을 실행한다. 하루 끝에 `stratus status`로 남은 것이 없는지 확인한다.
6. 하루 끝 점검: 콘솔에서 EC2(인스턴스, NAT 게이트웨이, 탄력적 IP, 볼륨, 스냅샷), RDS, SageMaker, 로드밸런서, WAF가 비어 있는지 확인한다.
7. GuardDuty는 체험 30일이 끝나기 전에 끌지 결정한다.
