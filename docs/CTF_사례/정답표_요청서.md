저는 대회 로그를 LogFinder(로그로 침해 흐름을 설명하는 도구)로 분석해, **도구만 보고 침해와 대응을 얼마나 맞게 판단할 수 있는지** 재려고 합니다.
제가 판단을 먼저 끝내고 봉인한 뒤에 이 기록과 맞춰 보기 때문에, **기록은 대회 중에 적어 주시고, 제가 요청하기 전에는 보내지 말아 주세요.**
풀이나 힌트를 대회 중에 저에게 알려 주시지 않아도 됩니다(알려 주시면 측정이 무효가 됩니다).

## 부탁드리는 것

1. **공격한 순간마다 한 줄씩** 적어 주세요. 나중에 기억으로 적으면 시각이 틀어집니다. 성공하지 못한 시도도 적어 주세요.
2. **정상 작업도 적어 주세요.** 운영 측의 점검 접속, 서버 재시작, 문제 초기화, 차단 같은 대응이 해당됩니다. 오탐을 재는 데 필요합니다.
3. **공격 IP**를 꼭 적어 주세요. 대회 중 IP가 바뀌었으면 바뀐 시각부터 새 줄에 적어 주세요.
4. 대회가 끝나면 그대로 보관해 주시고, 제가 "판정 봉인했습니다"라고 연락드리면 그때 보내 주세요.
