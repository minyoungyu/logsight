# 11/26 CTF 로그 3자 비교 평가 설계

같은 CTF 로그를 **세 평가자가 따로** 분석하고, 운영진 정답표와 맞춰 비교한다. 목적은 "LogFinder(AI 포함)가 사람 분석과 비교해 어디까지 맞히고, 어디서 틀리며, 얼마나 빠른가"를 숫자로 남기는 것이다.

| 평가자 | 무엇을 보고 | 비고 |
|---|---|---|
| A. 개발자 본인 | 원본 로그만(LogFinder 보고서를 보기 전) | 문제를 설계했으므로 의도한 풀이를 안다. 그래서 A의 점수는 참고값이고, 비교의 기준은 B다 |
| B. 외부 보안 담당자 1명 | 원본 로그만 | 실무자 기준선. 개발에 참여하지 않은 사람 |
| C. LogFinder (규칙+AI) | 원본 로그 → 자동 보고서 | 사람이 보고서를 고치지 않는다. 출력 그대로 채점 |
| (선택) D. 그냥 채팅 AI | 원본 로그를 붙여 넣고 질문 | [채팅AI_기준선_실험.md](../채팅AI_기준선_실험.md)와 같은 방식. 넣으면 "LogFinder의 구조가 보탠 몫"을 따로 볼 수 있다 |

"AI가 한 번"은 C(LogFinder의 AI 분석)로 읽었다. 채팅 AI 단독 비교가 필요하면 D를 더한다.

## 1. 공정하게 만드는 규칙

1. **같은 입력.** 로그 묶음 하나를 만들어 SHA-256을 적고, 세 평가자에게 같은 파일을 준다. 운영진 기록·CTFd 제출 기록·풀이 기록은 주지 않는다.
2. **따로, 먼저 봉인.** 각자 답안지(아래 양식)를 다 쓰면 파일 해시를 시각이 남는 곳(저장소 이슈 등)에 올린다. 세 답안이 모두 봉인된 뒤에만 정답표를 연다. 봉인 뒤에는 고치지 않는다.
3. **순서.** A는 LogFinder 보고서를 보기 전에 쓴다. B에게는 LogFinder 보고서를 보여 주지 않는다. C는 사람 손을 거치지 않는다.
4. **같은 시간 상한.** 사람 평가자는 2시간에서 끊는다. 걸린 시간은 실제 값으로 적는다(C는 자동 분석 시간).
5. **채점자는 평가자가 아닌 사람.** 정답표를 가진 운영진 1명이 채점한다. 애매한 항목은 채점 기준표에 먼저 적고 그대로 따른다.

## 2. 답안지 (셋 모두 같은 양식)

[사례_보고서_양식.md](사례_보고서_양식.md) 2.2·2.3절 표를 그대로 쓴다. 한 줄 = 한 주장.

| 칸 | 내용 |
|---|---|
| 팀(tNN), 시각, 출발 IP·계정 | |
| 무엇을 했나 | F1~F6 중 어느 단계, 또는 설계 밖 경로 |
| 결과 | 성공 / 실패 / 모름 |
| 근거 | 로그 파일:줄(사람도 적는다. 근거 없는 주장은 따로 센다) |
| 확신도 | 1~5 |

## 3. 채점

정답 단위는 **팀 × 단계**(예: t03-F2)와 운영진 조치다. 정답표에 있는 것만 정답이다.

| 지표 | 계산 | 무엇을 보나 |
|---|---|---|
| 단계 재현율 | 맞게 짚은 팀×단계 / 로그에 남은 팀×단계 | 놓치지 않나 |
| 결과 정확도 | 성공·실패를 맞힌 수 / 짚은 수 | **"실제로 뚫렸나"를 맞히나** (LogFinder의 핵심 주장) |
| 틀린 주장 수 | 정답표에 없는 단계·성공 주장 | 지어내나 |
| 근거 비율 | 근거(파일:줄)가 붙은 주장 / 전체 주장 | 확인할 수 있나 |
| 걸린 시간 | 로그를 받은 때부터 답안 끝까지 | 빠른가 |
| '모름'의 질 | 로그가 없어 알 수 없다고 한 것 중 실제로 로그가 없던 것 | 모르는 것을 아나 |

결과는 평가자별 한 줄 표로 낸다. 차이가 작으면 작다고 쓴다. 사건 수가 적어 통계적 결론은 내지 않는다.

## 4. 미리 정할 것 (대회 전)

- [ ] 외부 보안 담당자 섭외, 비밀 유지와 데이터 범위 동의(참가자 IP가 들어 있음)
- [ ] 채점 기준표: 설계 밖 경로를 어떻게 셀지, "부분 성공"을 어떻게 셀지
- [ ] D(채팅 AI)를 넣을지
- [ ] 봉인 기록을 올릴 곳

## 5. 한계

- 평가자 1명씩이라 개인차가 결과를 좌우한다. "LogFinder가 보안 담당자보다 낫다/못하다"로 일반화하지 않는다.
- CTF는 우리가 설계한 환경이다. 실제 고객 사고의 대신이 아니다.
- A는 정답을 거의 아는 상태라 A와 C의 비교는 쓰지 않는다. A의 쓰임은 "개발자가 자기 도구 없이 얼마나 걸리나"다.
