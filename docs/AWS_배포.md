# 데모 배포 가이드 (AWS, 안전 데모 모드)

공개 저장소에는 **계정 ID, 리전별 접속 주소, 자격증명, 비밀값을 적지 않는다.**
아래의 `<...>` 자리는 배포하는 사람이 자기 환경에서 채운다.

## 원칙

- 이미지는 `LOGSIGHT_DEMO=1`로 고정 실행한다. 업로드는 403, API 문서는 404, AI 호출은 꺼진다.
- 테스트 사이트(`lab/`)와 테스트 코드는 이미지에 들어가지 않는다(`.dockerignore`).
- 배포 환경에 `ANTHROPIC_API_KEY`를 넣지 않는다. 데모는 키가 없어도 동작한다.
- 접속 주소는 **외부 공유를 허락받기 전까지 공개하지 않는다.** 기본 설정은 서비스 URL을 아무에게도 알리지 않는 상태다.

## 권장 서비스

| 옵션 | 장점 | 주의 |
|---|---|---|
| **Lightsail 컨테이너** (추천) | 월 정액이라 $100 크레딧 안에서 비용을 예측하기 쉽다. HTTPS 기본 도메인 제공 | 요금·리전 옵션은 콘솔에서 확인 |
| App Runner | ECR 이미지를 그대로 쓰고 자동 확장·HTTPS를 준다 | 사용량 과금이라 한도를 콘솔 예산 경보로 걸어 둘 것 |
| EC2 + Docker | 자유도가 높다 | 보안 그룹·OS 패치를 직접 관리해야 함 |

데모 용도로는 **Lightsail 컨테이너(가장 작은 플랜)**를 추천한다. 정액이라 크레딧 소진 걱정이 적다.
요금표는 바뀌므로 배포 전에 AWS 콘솔의 요금 계산기로 한 번 확인한다.

## 배포 절차 (요약)

1. 이미지 빌드: `docker build -t logsight-demo .` (저장소 루트에서)
2. 로컬 확인: `docker run --rm -p 8000:8000 logsight-demo` 후 `http://127.0.0.1:8000/web/demo`가 열리는지 본다.
3. 컨테이너 서비스 생성 후 이미지를 올린다. 포트는 `8000`, 환경변수는 `LOGSIGHT_DEMO=1`(이미지에 이미 있음).
4. 예산 경보 설정: 월 사용액이 일정 금액을 넘으면 알림을 받도록 Budgets에서 만든다(예: $20).
5. 서비스 URL은 **외부 공유 허락 전까지 이 저장소 문서·이슈·PR에 적지 않는다.**

## 점검 체크리스트

- `/` `/web` `/web/demo` `/demo`는 200, `/docs` `/openapi.json`은 404
- `/analyze` `/web/scan` POST는 403
- 배포 환경에 AI 키가 없음
- 접속 정보와 계정 정보가 커밋되지 않았음(`git grep`으로 확인)

## 되돌리기·정리

서비스를 중지하거나 삭제하면 외부 접근이 즉시 끊긴다. 데모를 더 열어 둘 필요가 없어지면 바로 삭제한다.
