# 우리 팀 알아보기: 자기 팀 작업을 공격으로 보는 오탐 줄이기

측정일 2026-11-04 · 엔진: 이 브랜치(규칙은 바꾸지 않음, 판정 단계에 확인된 팀 목록만 더함)

## 왜 만들었나

작은 팀의 가장 흔한 오탐은 **자기 팀의 작업**이다. 공방전 측정에서 1위 사건(INC-001)은 블루팀의 조회 작업 432건이었고,
진짜 공격 사건은 2위였다. 이름 목록을 손으로 적어 주면 고쳐지지만(`known_activity`), 보안 담당자가 없는 팀은 그 목록을 만들지 않는다.

GuardDuty와 채팅 AI는 누가 우리 팀인지 모른다. LogSight는 로그만 보고 후보를 골라 **한 번 확인받는다.**

## 어떻게

`logsight team <로그>`가 아래를 모두 만족하는 계정을 후보로 보여 준다. 보고서에도 같은 후보가 나온다.

1. 사람 계정(IAM 사용자, SSO 역할). 루트, EC2 역할, 서비스 역할은 제외
2. 콘솔에서 직접 작업한 흔적(콘솔 로그인, CloudShell, IAM 사용자의 콘솔 세션 임시 키)
3. 로그 기간의 절반 이상 활동했거나, 설정 스냅샷에 있던 기존 사용자
4. 키 유출에서 흔한 모습(인스턴스 키 외부 사용, 거부 폭주, 허용 밖 IP)이 없음

확인(`--confirm 이름`)하면 `team.json`이 되고, `analyze --team`·`watch --team`이 이 계정들의 작업을 공격 판정에서 뺀다.
**확인 없이는 판정을 바꾸지 않는다.** 비밀번호를 훔친 공격자도 콘솔로 들어오기 때문이다. 확인 목록에는 와일드카드를 쓸 수 없다.

| | 판정 정확도(사건 7개) | 공격 사건 순위 | 후보 |
| --- | --- | --- | --- |
| 기존(목록 없음) | 4/7 | 2위 | - |

손으로 목록을 적었을 때와 같은 결과를, 이름을 미리 몰라도 얻는다. 남은 1개(INC-003, EKS 노드 역할이 AWS 안의 IP 두 곳에서 쓰임)는
"판단 불가"로 남는다. 이 기능은 표시된 이벤트 수(오탐 600건)를 줄이지 않는다. 판정과 순위만 바꾼다.

### Splunk attack_data AWS 표본 44개 (처음 보는 데이터)

후보를 잘못 고르는지(공격자를 우리 팀으로 제안하는지) 확인했다.

- 후보가 나온 표본 0개. 공격 행동을 한 계정을 우리 팀으로 제안한 경우 0건.
- 사람 계정 47개 중 콘솔 흔적이 있고 수상한 모습이 없는 4개는, 잠깐만 활동해 3번 조건에서 빠졌다.

한계: 이 표본에는 "오래 일한 진짜 팀원"이 없어서, 후보를 잘 찾는지는 재지 못했다. 공격자가 오래 활동하면 후보에 오를 수 있고,
그때는 사람의 확인이 마지막 방어선이다.

## SSH 로그(auth.log)를 뺐을 때

서버에 설치하지 않으면 auth.log를 못 받는다. 저장소 합성 샘플 두 개로 auth.log를 넣고 빼서 비교했다.

| 샘플 | 사건 수 | 공격 단계 | 달라진 것 |
| --- | --- | --- | --- |
| demo (이벤트 11 → 8) | 1 → 1 | 같음 | "SSH 무차별 대입 뒤 로그인 성공" 근거가 빠짐. 사건 점수 423 → 410 |
| combined (87 → 84) | 3 → 3 | 같음 | 같은 근거가 빠짐. 1위 사건 점수 434 → 422 |

다른 로그(VPC Flow의 22번 포트 노출, 인스턴스 키 외부 사용)가 사건을 지탱해서 사건과 단계는 그대로였고, 오탐도 늘지 않았다.
대신 보고서가 "SSH로 들어왔다"를 확인하지 못하고 "SSH가 열려 있었다"까지만 말한다. 합성 샘플 2개라 일반화할 수 없다.
공방전 데이터에는 auth.log가 원래 없다.

## 재현

    python scripts/ctf/convert_gongbang.py <통합로그.md> --out data/gongbang

    python -m logsight team data/gongbang --confirm blue-team-1 blue-team-2 --out team.json
    python scripts/ctf/eval_gongbang.py --data data/gongbang --env team.json --out reports/ctf/gongbang_team.json
