## 원인과 수정

1. **웹셸 오탐(필수)**: 웹셸 명령 인자 목록에 `c`가 있어서 `category.php?c=mouse`(상품 분류)가 모두 웹셸 접근으로 잡혔다. "/24 묶음"은 이 오탐 사건들을 공격자와 이어 붙인 2차 원인이었다.
   - `c=`·`run=`처럼 짧고 흔한 인자는 값이 명령처럼 생겼을 때만 센다(셸 기호, `/usr/`·`/bin/` 경로, 공백이 든 명령어, `id`·`whoami` 같은 단독 명령). `cmd=`·`exec=` 등은 그대로.
   - 공격 묶음의 '같은 /24 대역' 연결은 두 사건에 같은 규칙(수법)이 있을 때만 한다. 대회장 NAT처럼 한 대역을 여럿이 쓰는 경우를 막는다.
2. **SQLi 오탐**: UNION SELECT는 앞에 따옴표·숫자·괄호·주석이 있거나 뒤에 열 목록·NULL·FROM·주석이 올 때만 본다. `id=1 union select null`, `' UNION SELECT 1,2 --`, `/**/union/**/select/**/1,2`는 계속 잡는다.
3. **부팅 계정·운영자 신원**: 시스템 UID(1000 미만)+nologin 계정과 UID 1000의 클라우드 기본 계정(ec2-user 등)은 계정 생성 규칙에서 뺀다(sudo로 만든 것은 그대로 잡음). 운영자 계정은 `lab/ctf/environment.json`의 정상 작업 목록에 넣고, 정상 작업 이벤트는 IP로 다른 활동과 잇지 않게 했다.
4. **F1·F5 탐지 추가**: 위 표. F5를 POST 본문으로 보낸 경우(리허설 02:40의 `POST /admin/fetch.php`)는 접근 로그에 주소가 없어 여전히 못 본다. 그 뒤 단계인 역할 키 외부 사용(F6)은 CloudTrail로 잡힌다.
5. **중복 집계**: Amazon Linux 2023은 auth.log와 secure에 같은 줄을 남긴다. 수집 스크립트가 내용이 같으면 secure를 분석에서 뺀다.

## 남은 것

- 웹 로그의 일부 요청이 `127.0.0.1`로 잡힌 것(XFF 미설정 재현 요청)은 대회 당일 ALB 경유 트래픽에선 생기지 않는다.
- 운영자가 공격 재현과 같은 IP에서 작업했기 때문에 `CT_DISCOVERY_BURST`(IP 기준) 하나에 운영자 조회 12건과 탈취 역할 조회 1건이 함께 들어 있다. 판정은 탈취 역할 쪽 때문에 '공격'으로 맞다.
- ALB/WAF 로그는 아직 비어 있다(테스트 객체만 있음). ALB 보안그룹이 운영자 IP만 허용해서다.
