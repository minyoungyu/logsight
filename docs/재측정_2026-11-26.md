### 무엇이 달라졌나

- **lab 34/35**: 시나리오가 늘어 기대 규칙이 35개가 됐고, `idor_orders`(남의 주문 번호 25개 연속 열람)를 놓쳤다. 11/17에 IDOR 규칙이 사이트 프로필의 `private_object_paths`를 읽게 바뀌었는데, `lab/profiles/shopmall.json`에는 그 값이 없어 규칙이 꺼져 있었다(`samples/web/profile.json`에는 있음). 이 측정 숫자는 고치기 전 값으로 둔다.
- **flaws 시간**: 예전 1분 41초는 GitHub Actions 표준 러너, 이번은 4코어 컨테이너다. 같은 환경 비교가 아니다. `summary.md`의 "처리 22.47초"는 파일을 읽은 뒤 분석 단계만 잰 값이다. 사건이 늘어난 것은 11월 규칙 추가 때문이다.
- **BOTSv3 공격 판정 7→12**: 그 뒤 추가된 규칙(콘솔 MFA 없는 로그인 등)이 사건을 더 만들었다. 판정이 늘어난 사건이 실제 공격인지는 이번에 사람이 다시 보지 않았다.
- **CTF 비용**: 계산에 넣지 않은 S3·Flow Logs 전송·데이터 전송을 더하면 $15.7과 1달러 안쪽 차이다. ALB LCU와 WAF 요청 수는 가정값이다.

저장소에 등록된 AI 키(`LOGSIGHT_ANTHROPIC_KEY`)가 **401 invalid x-api-key**로 거절됐다(2026-11-26 13:4x KST, 두 번 시도). 그래서 아래 두 개는 이번에 재지 못했다.

- 채팅 AI 기준선 3/6: 대화 기록과 채점 파일을 남기는 방식으로 다시 해야 한다.

유효한 키를 받으면 같은 명령으로 3회 돌려 세 파일을 모두 커밋한다.

## 재현

```
# lab (nginx·php-fpm 필요)
bash lab/serve.sh start && python3 lab/attack.py
python -m logsight scan --profile lab/profiles/shopmall.json --no-ai --out lab/reports/shopmall
python -m logsight scan --profile lab/profiles/board.json --no-ai --out lab/reports/board
python3 lab/evaluate.py && bash lab/serve.sh stop

# flaws.cloud (데이터 파일 해시: flaws/data_sha256.txt)
curl -sSfL -o flaws.tar https://summitroute.com/downloads/flaws_cloudtrail_logs.tar && tar -xf flaws.tar
python -m logsight analyze $(find flaws_cloudtrail_logs -name '*.json.gz' | sort) --top 10 --no-ai --out reports/flaws

# BOTSv3 (꺼낸 파일 해시: botsv3/extracted_sha256.txt)
python scripts/public/botsv3_extract.py botsv3_data_set/var/lib/splunk/botsv3/db data/botsv3
python -m logsight analyze data/botsv3 --year 2018 --no-ai --out reports/botsv3
python -m logsight analyze data/botsv3 --year 2018 --no-ai --env reports/remeasure_2026-11-26/botsv3/staff_list.json --out reports/botsv3_list

# CTF 비용
python scripts/ctf_cost.py reports/remeasure_2026-11-26/ctf/cost_inputs.json
```
