그래서 이 로그로는 알 수 없는 것
  • CloudTrail 로그가 없어 AWS 계정에서 누가 어떤 API를 썼는지 알 수 없습니다.
  • VPC Flow 로그가 없어 어느 IP가 서버에 접속했고 데이터가 밖으로 나갔는지 알 수 없습니다.
  • WAF 로그가 없어 웹 공격 요청이 막혔는지 알 수 없습니다.
  • ALB 로그가 없어 웹 요청이 어떤 응답을 받았는지 알 수 없습니다.
  • SSH 인증 로그가 없어 누가 서버에 로그인했는지 알 수 없습니다.
  • INC-001의 활동이 로그가 끝나는 무렵(11-18 02:35 UTC(한국 11:35))까지 이어집니다. 그 뒤에도 계속됐는지는 알 수 없습니다.
'기록이 없음'은 '일어나지 않음'이 아닙니다. 빠진 로그는 python -m logsight check로 켜는 방법과 비용을 볼 수 있습니다.
